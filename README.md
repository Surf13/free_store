# FreeStore
FreeStore is a webstore/database project built with Next.js.

The project displays products stored in a database and includes product categories, product details, a shopping cart, and a checkout experience.

## Live Website
https://free-store-kappa.vercel.app

## Deployment
Hosted using Vercel.

## Project
This project was created as a database/webstore project to practice building a full-stack web application with Next.js, Prisma, and PostgreSQL.

The product images come from the Amazon Berkeley Objects (ABO) dataset. A small subset of the images has been uploaded and stored in a separate database for the project to use.

## Main Technology Used
- Next.js
- JavaScript
- React
- Prisma
- PostgreSQL
- Tailwind / CSS
